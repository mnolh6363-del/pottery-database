## About

A relational database design for **Fokhar & Co.**, a pottery business that sells ready-to-buy pottery pieces and runs pottery-making workshops and sessions.

The project covers:
- Narrative description of the business
- ER Model (Entity-Relationship Model)
- EER Model
- Relational Schema
- Normalization
- SQL implementation (tables, procedures, queries)

## Main Sectors

- **People** — Customer, Instructor/Staff
- **Experience** — Workshops, Sessions, Bookings
- **Production** — Pieces, Piece Status, Failure Log
- **Retail** — Products, Sales/Invoices
